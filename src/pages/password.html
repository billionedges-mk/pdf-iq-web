The password never leaves this tab.

It is used here, by your own browser's cryptography, to derive the file's key. It is not sent anywhere, not stored, and not written into the file you save.

Removing a password does not lift an author's limits.

If a file's author limited printing, copying or editing, only their owner password lifts that. With the password that merely opens the file, your copy opens without one and keeps those limits.

AES-256, and nothing older.

Anything this page protects is written as AES-256 (Standard V5 R6). Your original is never modified — saving produces a new file beside it.
