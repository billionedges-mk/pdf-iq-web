Order is yours, not ours.

Merging is the one job where file order matters and every tool gets it wrong. Yours arrive in the order you dropped them, and nothing is written until you say so.

No upload, so no deletion policy.

Other tools promise to delete your files in an hour. Yours were never on our disk, so there is no promise to keep.

    What gets kept

    • Every page, at its original size and quality.
    • Bookmarks, nested under each source file's name.
    • Links inside a file. Links pointing between files cannot survive a merge.
    • Form fields, renamed where two files use the same name — sharing a name in PDF means sharing a value.
    • Mixed page sizes stay mixed. We will not scale an A4 contract to fit a Letter cover page.
