Why there is no upload bar

The tools are JavaScript, shipped with the page like a stylesheet. Once loaded they run against a file your browser holds in memory. Only OCR fetches anything further, and only the first time you use a language.

Test it in ten seconds

Load a tool, disconnect from the internet, then use it. It still works. Nothing that needs a server survives that test.

Nothing to delete

Other tools promise to erase your file within an hour. Yours was never on our disk, so there is no promise for us to keep or break.
