Seven PDF tools that run inside this tab.

Your file is opened by your browser, changed on your device, and saved back to your disk. There is no upload step because there is nowhere to upload to.

Compress PDF Make a file smaller for email or a filing. We tell you the real before and after, and say so when it cannot get smaller. Merge PDF Combine files into one, in the order you set. Drag to reorder before you save. Split PDF Pull out a page range, or cut one document into several. Page count has no limit here. Images to PDF Turn photos or scans into one document. Phone photos of receipts are the usual case. Rotate pages Fix sideways scans. Turn every page at once or only the ones that are wrong. Reorder pages Move or delete pages on a grid of the real pages, then save the new order. OCR — make searchable Read the text in a scan so you can search and copy it. Slowest tool here, and worth the wait.

Why there is no upload bar

The tools are JavaScript, shipped with the page like a stylesheet. Once loaded they run against a file your browser holds in memory. Only OCR adds anything further, and only the first time you use it.

Test it in ten seconds

Load a tool, disconnect from the internet, then use it. It still works. Nothing that needs a server survives that test.

No account, no queue, no watermark

There is no server cost per file, so there is nothing to meter. Use it twice or forty times a day.
