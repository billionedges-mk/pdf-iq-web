Memory probe

Finds the largest PDF this device can actually get through, by building one and doing the work. It is here so the ceiling on the tools is a measured number rather than a guess. Not linked from anywhere and not indexed.

Before you start

This deliberately pushes the tab until it fails. It will go unresponsive for minutes at a time, and on a phone it will probably be killed outright. That is the measurement, not a fault.

Every rung is written down before it is attempted, so a crash loses nothing — reopen this page afterwards and it will tell you where it died. Nothing is read from your files: every test document is generated here, in the page.
