Support

Email support@pdf-iq.com. One person reads it, usually within two working days.

Please do not attach the document you had trouble with. We cannot see your files by design, and we would rather keep it that way — the file name, the tool you used, your browser and what happened is enough to work from.

A tool said my file is damaged, but it opens elsewhere

Some viewers repair a broken page index silently on open. We tell you instead, because a repair can change which pages end up in the result. Ask us and we will look at the specific error text you saw.

Compression barely changed my file

Then it was already close to its practical floor, and the result page tells you why using the actual image format, quality and resolution it found in your document rather than a stock sentence. If you need to hit a specific size, email the number and we will tell you whether it is reachable.

Something failed with a large file

Because processing happens in your browser, the ceiling is your device's memory rather than an upload limit. Splitting a very large file first almost always works, because splitting copies pages rather than rendering them. We are still measuring real-world limits on real phones before we publish a number.

Does it work offline?

Yes. Load a tool once, then disconnect and use it. That is the simplest way to confirm for yourself that nothing is being uploaded.

OCR is the one partial exception: it needs to fetch its language model the first time you use a given language. After that it is cached and works offline too.

OCR is slow

It is the heaviest tool here, because every page has to be drawn and then read a word at a time. It uses several of your processor's cores at once to keep that bearable, and once it has read enough pages to know, it shows you the measured rate and how long is left. You can switch to another tab while it runs; it keeps going.

The first run in a given language also downloads that language's model, which is between 6 MB and 11 MB. That happens once and is then cached.

Some pages came back without text

We would rather name the pages we could not read than quietly average them into a success. Handwriting is not attempted, blank or photographic pages have nothing to find, and very noisy scans can come back too uncertain to trust. The result panel lists which pages and why.

An iPhone photo would not open

Recent iPhones save photos as HEIC, which Safari can read but Chrome and Firefox cannot. Sharing the photos out of the Photos app usually converts them to JPEG on the way, or you can set Camera → Formats to "Most Compatible" so the phone writes JPEG in the first place.

Reporting a security issue

Email the same address with "security" in the subject. We answer these first, and we will credit you if you want the credit.

Helpful in an email

  • The exact message on screen, or a screenshot of it.
  • Browser and version, or phone model for the app.
  • Roughly how big the file was, and how many pages.
